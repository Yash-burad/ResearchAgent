# Autonomous Execution & Permissions

- **Autonomous Code Edits**: You have full permission to create, modify, and refactor code directly to solve tasks without asking for confirmation.
- **Autonomous Testing**: Always run relevant tests (e.g., `pytest`, test suites, or verification scripts) after making changes to verify correctness.
- **Self-Healing**: If tests fail or commands encounter errors, analyze the output, fix the code immediately, and re-run tests until everything passes.
- **Commands & Searches**: You have full permission to execute any read, search, build, test, lint, and internet search commands needed to complete the task.
- **Safety**: Never delete files without explicit user instruction.
